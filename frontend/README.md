# Frontend Module — UK Tutoring Platform

This directory contains all presentation-layer assets and view templates for the UK Tutoring Platform.

## Structure
- `public/`: Public document root containing static assets (`assets/css`, `assets/js`, `assets/images`, `assets/fonts`) and web entry points.
- `views/`: Domain-separated view templates:
  - `layouts/`: Master header and footer templates.
  - `components/`: Reusable UI components (navigation, alerts, badges).
  - `public/`: Public presentation pages.
  - `auth/`: Authentication views.
  - `student/`: Student and parent workflow templates.
  - `tutor/`: Tutor profile, availability, and booking management templates.
  - `manager/`: Managerial administrative desk templates.
