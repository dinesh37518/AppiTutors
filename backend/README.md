# Backend Module — UK Tutoring Platform

This directory contains the core PHP 8 application services, API endpoints, domain models, and configuration.

## Structure
- `api/`: RESTful JSON API endpoints grouped by domain (`auth/`, `tutors/`, `students/`, `bookings/`, `availability/`, `manager/`, `blog/`, `newsletter/`).
- `src/`: Business logic services, domain models, validation, and support utilities.
- `config/`: Application, database, mail, and Firebase configuration files.
- `routes/`: Explicit API and web route maps.
- `bootstrap/`: Application initialization and error handling setup.
